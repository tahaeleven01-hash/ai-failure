# AI Failure Cases Directory

This directory stores verified, community-submitted AI agent failure cases.

## Contribution Guidelines

1. Each case must have its own directory named according to its Case ID (e.g., `failures/AFM-0001/case.yaml`).
2. Real-world failures must be verified and must never contain fabricated evidence, private API keys, or confidential source code.
3. Every case must conform to `schemas/failure-case.schema.json`.
4. Run `afm validate` before submitting a Pull Request.
